# Adding Conditions and Events
Add a condition and select the event that starts the journey, such as:
* Time-based triggers
* Order placed
* Birthday or anniversary
* Signs up for loyalty programs
* Choose the date range for which you wish to run this strategy.
* Specify the time during which the event should be captured.
* Select a combination of days for the event capture. For 24/7 coverage, enable the toggle button.
