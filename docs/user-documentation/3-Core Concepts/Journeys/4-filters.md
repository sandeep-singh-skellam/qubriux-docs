# Configuring Filters within a Trigger
Within a trigger, you can add filters such as:
* Specific store
* Amount spent
* Number of items
* nth lifetime order
* nth value after journey start
* On every nth value
* Customer attributes
* Store name

Once filters are configured, click Save to finalise the trigger setup.
