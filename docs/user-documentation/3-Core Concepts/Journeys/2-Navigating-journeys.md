# Introduction to Journey Builder
Journey Builder allows you to automate your marketing workflows in an intelligent and efficient way. A Journey Builder is an automated sequence that is set in motion by a specific trigger and then includes one or more steps. It simplifies the process of initiating and nurturing relationships with your customers throughout their lifecycle. By automating messages, you can grow your business and build customer loyalty.


# End of a Journey flow
The end flag marks the end of the strategy. This signifies that last step and further this, no processing is involved. 

# Editing a Strategy
You can edit a journey by clicking on the edit button below actions.

![image info](/img/journeys/3-journeys.png)

>[!TIP]
> Active and Scheduled strategies can not be edited. You first need to deactivate it to edit it.


# Deleting a Strategy
* You can delete a strategy by clicking on the delete button.
* Active and Scheduled strategies can not be deleted. You first need to deactivate it to delete it. 

# Block Operations

# Editing a block
To edit a block, click on the edit button in the three dots menu. The right pane will open where you can change the configuration. 

![image info](/img/journeys/4-journeys.png)

# Cloning a block 
To clone a block, click on the clone button in the three dots menu. The canvas will show you the valid places to clone. Choose a place by clicking on it and the block will be cloned. If you wish to cancel the operation, you can click on the cancel button on the right top. 

![image info](/img/journeys/5-journeys.png)

# Moving a block 
To move a block, click on the move button in the three dots menu. The canvas will show you the valid places to move. Choose a place by clicking on it and the block will be moved to that place. If you wish to cancel the operation, you can click on the Cancel button on the right top. 

# Deleting a block 
To delete a block, click on the delete button in the three dots menu.

![image info](/img/journeys/6-journeys.png)

# Deleting branching block - You can delete:
* Delete the condition block along with the Yes path block. The No path block gets appended to the parent of the condition block. 
* Delete the condition block along with the No path block. The Yes path block gets appended to the parent of the condition block. 
* Delete condition block along with all child blocks 

![image info](/img/journeys/7-journeys.png)

# Deleting other blocks - 
* Delete this - This will delete only the specific block and the rest of the blocks below get appended to the parent of the deleted block.
* Delete this and all after this - This will delete the selected block and all other child block attached below the selected block. 

**Adding a note** - You can add a note for your own reference by clicking on add note button in the three dots menu. After typing your note, click on save.

![image info](/img/journeys/8-journeys.png)

A block that has notes attached will be shown. The note is only for your reference and is not shared with customers.


# Status of a Journey Strategy
* Active - A journey that is running is shown with Active Status
* Ended - When a journey is deactivated, it is shown with Ended status
* Scheduled - A Journey is Scheduled when it is supposed to be active in the future. For e.g. if you create a strategy and mark the dates for 10 days in the future, it will remain in Scheduled and change to active on the 10th day.
* Draft -A strategy is in draft status when the configuration is underway and it was not activated.
