# App Analytics

App Analytics tracks how customers are interacting with your mobile app - covering user activity, session behaviour, event patterns, geographic distribution, and push notification engagement. All metrics can be filtered by date range and, where applicable, by city or event type.

## User Counts

| Metric | Description |
|--------|-------------|
| Active Users | Total users who performed at least one event in the selected period |
| New Users | Users who opened the app for the first time in the selected period |
| Login Drop-Off Users | Users who started the login flow but did not complete it |
| Push Opt-In Users | Users who have opted in to receive push notifications |

## Daily, Weekly & Monthly Active Users

Track engagement consistency over time:

- **Average DAU** (Daily Active Users) - average number of unique users active per day
- **Average WAU** (Weekly Active Users) - average number of unique users active per week
- **Average MAU** (Monthly Active Users) - average number of unique users active per month

These metrics help you understand whether your app engagement is growing, stable, or declining.

## User & Event Trends

- **Daily Event Trend** - total app events fired per day over the selected period, showing overall activity volume.
- **Daily User Trend** - unique users active per day, showing how your engaged audience fluctuates over time.

## Hourly & Frequency Distributions

- **Hourly Unique User Event Distribution** - a breakdown of when during the day your users are most active, grouped by hour bucket. Useful for timing push notifications and in-app messages.
- **User-Wise Event Frequency Distribution** - shows how events are distributed across users - for example, how many users triggered an event 1 time, 2–5 times, 6–10 times, and so on.
- **Percentage of Users with Event More Than N Times** - the share of your user base that has triggered a specific event more than a defined threshold, useful for identifying power users.

## Event Headline Counts

For any specific event type (e.g. `app_opened`, `offer_viewed`, `loyalty_checked`), view a summary of:

- **Total events** - total number of times the event was fired
- **Unique users** - distinct users who triggered the event
- **Unique devices** - distinct devices that fired the event

## Geographic Breakdown

- **Most Active Cities** - ranked list of cities by user activity, showing where your app engagement is concentrated.
- **City Filter** - filter all app analytics metrics by a specific city.

## App Downloads

View app download counts broken down by **platform** (iOS vs. Android) to understand where your audience is acquiring the app.

## Engagement Drop Analysis

- **Engagement Drop After Time Window** - the percentage of users who first opened the app within a given window but did not return after a set period. Identifies cohorts at risk of churning from the app.

## Push Notification Engagement

| Metric | Description |
|--------|-------------|
| Push Open Rate | Percentage of delivered push notifications that were opened |
| Push Click-Through Rate | Percentage of push recipients who tapped through to the app |
| Push Opt-In Drop-Off | Users who were prompted to opt in but declined |
