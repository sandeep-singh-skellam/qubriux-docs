The Qubriux Loyalty Open API enables external POS systems, mobile applications, and
third-party integrations to interact with the Qubriux loyalty platform. It covers the
full customer loyalty lifecycle — from registration and offer retrieval through to reward
validation and post-transaction redemption confirmation.

## Authentication

All endpoints require a **merchant-level API Key** passed as the `api_key` field in every
request body. This key is issued by Qubriux during integration setup.

Most endpoints also accept an optional **JWT Bearer Token** in the `Authorization` header.
Obtain a token from `POST /openapi/auth/getAccessToken`. When provided, the JWT is validated
against the merchant context derived from the API key — a mismatch results in a 401.

```
Authorization: Bearer <jwt_token>
```

## Response Envelope

All responses (except `getLoyaltyTierDescription`) use a standard wrapper:

```json
{ "status": "success", "data": { ... } }
```

On error, `status` is `"failure"` and `data` contains the error message string.
